LEDGDEX DIRECTORY STRUCTURE


This list shows the files that ledgdex init shop ... makes. Nothing in the folder is secret. Keys are never in a dex.

shop/
  ledgdex.jsonl        the ledger: a header line and one signed entry for each line (it only grows)
  data.json            the dex pages: your pages, and the pages that ledgdex writes (they start with <!-- ledgdex -->)
  config.json          dexweb settings, "publish" (with "append_only": ["ledgdex.jsonl"]) and "ledgdex"
  styles.css           the look of the site (the dexweb default)
  run.py               "python run.py" builds the dex with dexweb, as in any dex
  to_add/              files that dexweb adds as pages
  backup/              the dexweb backup of data.json
  gen/                 the website: the published files, with gen/ledgdex.jsonl
  .ledgdex-root.jsonl  the last copy of the root that ledgdex read (only with a root, never published)
  .ledgdex.lock        lets one writer change the dex at a time
  .publish/            the dexweb copy of the repository that it publishes to

~/.ledgdex/            secret keys, mode 600 (NAME.key), and secret bids until their reveal (bids/)
~/.cache/ledgdex/      a record of the ledger bytes that ledgdex verified before (for speed only)

Ledgdex publishes only gen/. The command ledgdex render shop writes the generated pages again and builds gen/ again. Each command that records an entry does this for you.
