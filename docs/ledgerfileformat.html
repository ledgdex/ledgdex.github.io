LEDGER FILE FORMAT


A ledger is UTF-8 text, one canonical JSON value per line, each ending with a newline: a header, then entries. Canonical JSON: keys sorted, no spaces, integers only (no floats), at most 32 levels deep, one spelling for each value (spec 1.2). The ledger id is the SHA-256 of the header line; an entry's id is the SHA-256 of its line.

The header: {"ledger": 1, "name": str, "owner": key}. Each entry: {"seq": n, "prev": id of the previous entry (or the ledger id), "time": time, "msg": message, "sig": ...}, signed by a current signing key (the owner, or an active device key). The first entry records open.

A ledger is whole when every line verifies in order: the hash chain, the signatures, the times, and who may record what. Change one byte and verification breaks at that line. 

ledgdex verify https://ledgdex.github.io/docs

A receipt ({"ledger", "url", "header", "entry", "keys"}) verifies on its own: the other ledger's header and its signed entry, with the key entries that lead to the key that signed it.
