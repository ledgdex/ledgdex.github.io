LEDGER FILE FORMAT


A ledger is UTF-8 text. Each line is one canonical JSON value and ends with a newline. The first line is a header. The other lines are entries.

Canonical JSON has these rules (spec 1.2):

- Keys are in sorted order.

- There are no spaces.

- Numbers are integers only, with no floats.

- Values have at most 32 levels.

- Each value has one spelling only.

The ledger id is the SHA-256 of the header line. The id of an entry is the SHA-256 of its line.

The header: {"ledger": 1, "name": str, "owner": key}.

Each entry: {"seq": n, "prev": id of the previous entry (or the ledger id), "time": time, "msg": message, "sig": ...}.

A current signing key signs each entry: the owner key, or an active device key. The first entry records open.

A ledger is whole when each line verifies, in order: the hash chain, the signatures, the times, and the keys that can record each type.

If you change one byte, verification breaks at that line. 

ledgdex verify https://ledgdex.github.io/docs

A receipt ({"ledger", "url", "header", "entry", "keys"}) verifies alone. It holds the header of the other ledger and the signed entry.

It also holds the key entries that lead to the key that signed the entry.
