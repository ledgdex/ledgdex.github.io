EXAMPLE: SHOP WEB PAGE


A web page that shows a shop's offers, read from its ledger and checked in the reader's own browser.

Run it: Save it as a file and open it in a browser, or put it on your website.

<!DOCTYPE html>
<html lang='en'>
<head>
<meta charset='utf-8'>
<meta name='viewport' content='width=device-width, initial-scale=1'>
<title>Mango Farm: today's offers</title>
</head>

The page shows a line while it works, and a list that the script fills in.

<body>
<h1>Today's offers</h1>
<p id='status'>Checking the shop's ledger...</p>
<ul id='offers'></ul>
<script type='module'>

Load the JavaScript core from the ledgdex site. For a real shop, copy js/ from a release onto your own site and load it from there.

import { Ledger } from 'https://ledgdex.github.io/viewer/core.js';
import { state } from 'https://ledgdex.github.io/viewer/state.js';
import { amount } from 'https://ledgdex.github.io/viewer/render.js';

Read the shop's ledger. This one is the ledger of these docs: put your shop's address here. The site that serves it must let other sites read it; GitHub Pages does.

const SHOP = 'https://ledgdex.github.io/docs/ledgdex.jsonl';
const res = await fetch(SHOP);
const led = new Ledger(new Uint8Array(await res.arrayBuffer()));

Check every hash and signature in the reader's own browser, then list the open offers. Text from a ledger goes in with textContent, never as HTML, so nothing written in a ledger can run on your page.

const status = document.getElementById('status');
if (!led.whole) {
  status.textContent = 'This ledger is broken at entry ' + led.broken_at + ': ' + led.error;
} else {
  status.textContent = led.header.name + ': whole, ' + led.entries.length + ' entries';
  const list = document.getElementById('offers');
  for (const [id, o] of Object.entries(state(led).offers)) {
    if (o.status !== 'open') continue;
    const offer = led.entries[led.index.get(id)].msg.body;
    const item = document.createElement('li');
    item.textContent = o.title + ': ' + amount(offer.currency, offer.price) + ' per ' + offer.unit + ', ' + o.remaining + ' left';
    list.append(item);
  }
}
</script>
</body>
</html>
